# @deepseek-ai/dsh-client-ui-settings-connectors

[English](README.md) | 中文

Web 设置中的**连接器**页：用户把另一台机器变成本部署执行目标的唯一入口。浏览器插件通过 `ctx.slots.inject()` 注册一条 id 为 `connectors` 的本地化 `settings.section` 贡献，因此无需引入分区的拥有者即可跟随语言切换与拆卸。全部读写都经 [`api-remotes`](../../api/remotes/README.zh.md) 打到 `connectorPortal` Remote；宿主一侧是 [`host-connector-portal`](../../host/connector-portal/README.zh.md)。

选择 Linux、Windows 或 macOS 会铸出一条登记记录，并渲染启动其 agent 的两种等价方式：一条可复制的单行命令（`curl … | bash`，Windows 上为 `irm … | iex`），以及把同一段生成脚本存为文件的下载链接。两者抓取的是同一份脚本，因此两条路径运行的是同样的代码。脚本携带一份永不过期的按机器密钥：当宿主报告下载无期限时，页面会直说这一点而不是显示倒计时，因为机器掉线后会用同一密钥自动重连。其下列出已经拨入的机器，各自带有状态与一个「永久有效 · 可重连」标记；已接入的还会给出连接器 id 与所服务的工作目录，旁边是吊销登记记录并断开其 agent 的操作。

已接入的机器带着让它真正可用的两个操作。**测活**沿实时 link 完成一次真实往返，报告时延与目标机器自己解析出的工作目录；若无人回应，则给出入口那句可据以行动的说明。它随后会重读账本，因为一台不再回应的机器已经不是上方那一行所声称的「已连接」。**用此机器对话**按入口指名的 preset 创建一场绑定该连接器的对话，以目标机器的工作目录为 cwd，选中它，并关闭设置面板让用户直接落到这场对话上；被拒绝时面板保持打开，停在给出原因的那一行。只有在挂载了对话流程、且入口报告本部署能够绑定会话时，这个操作才会出现；若挂载了却不能绑定，该行会直说原因，而不是给出一个会悄悄跑在 harness 机器上的按钮。

页面打开期间每四秒轮询一次账本，因此用户刚启动的机器无需刷新即会出现；列表标题旁另有手动刷新。铸出失败、读取账本失败、测活失败与开对话失败都只停留在对应那一行，并且可以重试。源与剪贴板由客户端插件注入而非从全局读取，这让组件保持为其 props 的纯函数。

## 模型体验

无，因为本包只在浏览器设置中驱动一份 Host 拥有的登记账本，不注册任何模型接口。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **连接器对话没有工作区** — 这场对话不归属任何分组，因为工作区是承载本部署那台机器上的目录，而连接器对话的 cwd 是目标机器自己世界里的目录。
- **测活结果不持久** — 结果只存在于发起它的那一行，重新打开页面即消失；账本不保留任何测活历史。
- **轮询节奏固定** — 账本按页面自有的间隔刷新，没有实时推送，因此状态变化会在一个轮询周期内可见，而非立即可见。
- **一次只展示一张票据** — 签发新的 pack 会替换屏幕上的命令与下载链接；更早的票据在宿主侧依然有效，只是不再展示。
